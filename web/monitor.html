Live connection and run control

Offline
The monitor starts the machine stopped at the reset vector. Use Continue to run. Run-control commands are refused while GDB owns the session. Requests are authorized by Host/Origin, and when started with a token (--monitor-token=) the WebSocket URL must carry it (?token=, inherited from this page's URL). It binds to 127.0.0.1 unless you explicitly choose another IPv4 address.
